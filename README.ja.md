# mdfmtjp

独自のルールに基づく日本語ドキュメント向けMarkdownフォーマッターです。

## 機能

`mdfmtjp` は現在のディレクトリ内のすべての `.md` ファイルを自動的にフォーマットします。

- **文字の正規化:** 日本語テキストで一般的な句読点やスペースを標準化します。
  - `．` → `.`
  - `,` → `、`
  - `｡` → `。`
  - `　` → ` ` (全角スペースを半角に変換)
  - `＃` → `#`
  - `･` → `・`
- **番号付きリストの正規化:** 番号付きリストにおいて、番号の後にピリオドと半角スペース1つが続くように整形します（例: `1.item` は `1. item` に修正されます）。

## 要件

- [Deno](https://deno.land/) ランタイム

## インストール

```bash
deno install --allow-read --allow-write https://code4fukui.github.io/mdfmtjp/mdfmtjp.js
```

## 使い方

Markdownファイルが保存されているディレクトリに移動し、以下のコマンドを実行します:

```bash
mdfmtjp
```

スクリプトは現在のディレクトリ内のすべての `.md` ファイルを検索し、フォーマットを適用してファイルを上書き保存します。変更が加えられたファイルの名前はコンソールに出力されます。

### 例

**変更前:**
```markdown
＃＃＃＃ 1.あいう
2.いい
```

**変更後:**
```markdown
#### 1. あいう
2. いい
```

## アンインストール

```bash
rm $(which mdfmtjp)
```
